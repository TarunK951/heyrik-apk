# Brand assets

Exported from the rendered public HeyRik website for this requested frontend recreation on 14 November 2026.

- `long.png`, `short.png`: original wordmark and mark.
- `login-art.jpg`, `hero.jpg`, `footer.jpg`: original website artwork.
- `mesh-*.jpg`, `orb-*.jpg`: original gradient and orb artwork.
- `Geist.ttf`, `GeistSemi.ttf`: static instances of the rendered site's Geist web font (weights 400 and 600), converted with fontTools for native compatibility.
- `app-icon.png`: square native packaging of the waveform motif, drawn as rounded vector bars; the original web mark is not square.

Original sources are on https://www.heyrik.com/ and its `/art/` and `/_next/static/media/` asset paths. No browser session values, private records, or credentials are included. Branding remains associated with its owners; the template's code license does not grant third-party brand rights.
